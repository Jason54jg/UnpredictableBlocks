Variations

Variations

En plus de l'événement fixe du thème, chaque cassage peut tirer des variations bonus : le même bloc ne donne jamais deux fois la même chose.

On top of the theme's fixed event, each break can roll bonus variations: the same block never plays out the same way twice.

Variantes de bloc

Block variants

Un Lucky Block naturel a ~11 % de chance d'être spécial. La variante est visible (teinte / taille) avant de le casser.

A natural Lucky Block has a ~11% chance to be special. The variant is visible (tint / size) before you break it.
