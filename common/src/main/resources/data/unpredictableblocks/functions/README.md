# Fonctions / QA

Préférez les commandes ops :

- `/unpredictableblocks givekit` — tous les Lucky Blocks
- `/unpredictableblocks event <theme> <high|neutral|low>` — déclenche un événement
- `/unpredictableblocks place <theme> [luck]` — pose un bloc test

Thèmes : `boulangerie`, `casino`, `invasion_memes`, etc. (voir `LuckyTheme`).
