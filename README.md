# UnpredictableBlocks — GitHub Pages Wiki

Site statique de la branche `gh-pages`.

## URL

Après activation dans **Settings → Pages → Deploy from a branch** (`gh-pages` / `/`) :

`https://jason54jg.github.io/UnpredictableBlocks/`

## Contenu

| Page | Rôle |
|------|------|
| `index.html` | Accueil |
| `installer.html` | Installation Fabric / NeoForge |
| `guide.html` | Gameplay, chance & pourcentages |
| `crafts.html` | Recettes de craft |
| `themes.html` | Catalogue des thèmes |
| `bestiaire.html` | Bestiaire : 43 mobs GeckoLib (rendus 3D, PV, dégâts) |
| `variations.html` | Variantes de bloc, variations bonus, équipement custom |
| `mondes.html` | Profils monde / Parcours |
| `commandes.html` | Commandes & config |

Assets : `assets/branding/` (logo & key art du dépôt `main`), `assets/items/` (icônes de craft),
`assets/mobs/` (rendus isométriques des modèles `geckolib/models/entity/*.geo.json` + textures du dépôt `main`).
